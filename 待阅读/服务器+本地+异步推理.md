# 服务器 + 本地 Isaac Sim 异步推理

[查看演示视频（MKV，16.5 秒）](./服务器+本地+异步推理.mkv)

## 最终实现

正式流程固定使用两个终端：

```text
服务器终端
  LeRobot Policy Server
  加载 ACT checkpoint
  observation -> 60 步 action chunk

本机终端
  Isaac Sim + IsaacLab
  state + front + wrist -> SSH 隧道 -> Policy Server
  本地 action queue -> 30 Hz 策略动作 -> 60 Hz 仿真步进
```

服务器必须运行 Policy Server。本机客户端只负责仿真、观测采集、SSH 隧道和动作执行，
不会在本机加载 LeRobot 模型，也不会连接真实机器人。

## 启动服务器

服务器实例开机后，在服务器终端登录：

```bash
ssh -p 31361 root@183.147.142.40
```

进入服务器后启动 Policy Server：

```bash
cd /root/gpufree-data/lwh_policy_server

/root/lerobot/.venv/bin/python serve_lerobot_policy.py \
  --host 127.0.0.1 \
  --port 8080 \
  --fps 30
```

看到 `[策略服务端] 已启动` 后保持终端运行。不要关闭该终端，也不要把服务放到后台。

## 启动本机

打开本机终端：

```bash
conda activate isaac
cd /home/a/lwh_code/lwh_robot_learning
python3 scripts/run_policy_client.py
```

本机客户端自动读取：

```text
configs/remote_policy_server_config.py
```

配置中已经保存 SSH 地址、端口和密码，因此本机客户端会自动建立 SSH 隧道。出现
`[策略客户端] 已就绪，等待按 B 开始` 后，将焦点放到 Isaac Sim 窗口。

```text
B：发送当前观测，收到首个动作块后开始控制
R：停止当前策略并重置，结果记为失败
N：停止当前策略并重置，结果记为成功
Ctrl+C：退出客户端并关闭本机 SSH 隧道
```

R/N 后策略保持停止，需要再次按 B 才会开始新的推理过程。

## 配置修改

配置文件顶部已经说明各参数用途。服务器实例变化时通常只修改：

```python
# 服务器 IP 地址
host = "183.147.142.40"

# 云平台映射的 SSH 端口
port = 31361

# SSH 登录密码
password = "服务器密码"
```

模型或服务器目录变化时再修改：

```python
policy_path = "/root/.../checkpoints/030000/pretrained_model"
server_python = "/root/lerobot/.venv/bin/python"
server_script = "/root/gpufree-data/lwh_policy_server/serve_lerobot_policy.py"
```

真实配置文件权限为 `600`，并被 `.gitignore` 排除，不会把密码提交到 GitHub。仓库只
提交无真实密码的 `configs/remote_policy_server_config.example.py`。

## 异步参数

当前正式配置：

| 参数 | 值 | 作用 |
| --- | ---: | --- |
| 仿真控制频率 | 60 Hz | IsaacLab 每秒执行 60 个物理步 |
| 策略动作频率 | 30 Hz | 与训练数据 FPS 一致 |
| `actions_per_chunk` | 60 | 每次推理返回约 2 秒动作 |
| `chunk_size_threshold` | 0.65 | 队列剩余约 39 步时预取下一块 |
| `render_interval` | 2 | 每两个物理步更新一次相机和渲染 |
| 策略相机 | front + wrist | 与训练输入一致 |
| overview | 不发送 | 只用于人工观察 |

服务器推理和本机动作执行相互独立。本机执行当前 action queue 时，后台线程上传最新观测
并接收下一块动作，因此公网传输不会阻塞每一个仿真步。

## 正确关闭

按以下顺序关闭：

1. 本机客户端终端按 `Ctrl+C`，关闭 Isaac Sim 和 SSH 隧道。
2. 服务器 Policy Server 终端按 `Ctrl+C`，关闭服务端进程。
3. 确认不再使用后，在云平台关闭服务器实例。

关闭 SSH 窗口不一定等于关闭后台进程。正式流程要求 Policy Server 保持前台运行，避免
服务残留。服务器端可用下面的命令检查：

```bash
pgrep -af serve_lerobot_policy.py
```

本机检查 SSH 隧道：

```bash
ss -ltnp | grep 18080
```

两条命令都没有对应输出时，说明服务和隧道已经停止。

## 常见问题

### 本地提示 18080 被占用

先确认是否还有旧客户端或 SSH 隧道：

```bash
ps -ef | grep -E "run_policy_client|ssh.*18080"
```

不要在已有客户端运行时重复启动第二个客户端。

### 客户端收不到动作块

依次检查：

1. 云服务器实例是否开机。
2. 服务器 Policy Server 是否打印“已启动”。
3. `remote_policy_server_config.py` 中的 IP、SSH 端口和密码是否为当前实例信息。
4. 服务器 checkpoint 路径是否存在。
5. 本机日志中的“动作块”是否持续增加，“最近错误”是否为“无”。

### 服务器终端关闭后服务仍然存在

说明服务曾经被放到后台。可在服务器执行：

```bash
pkill -TERM -f serve_lerobot_policy.py
```

确认旧服务停止后，再按正式流程以前台方式启动。
